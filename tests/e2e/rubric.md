# 交互式代码地图端到端验收量表

本量表用于检查一次真实的“代码目录 + 业务问题 → MapSpec → 单个 HTML”生成。它不比较字节级快照；每项必须有清晰的通过或失败结论。

| 维度 | 通过条件 | 失败示例 |
| --- | --- | --- |
| 图谱范围 | 节点、边和分组回答了输入问题，范围没有无依据地扩大 | 将未读取的模块写成已实现流程 |
| 证据可追溯 | 所有 verified 项都有存在的相对路径、真实行号和准确描述 | 行号越界、文件不存在、把推断标成 verified |
| 证据状态诚实 | inferred 与 unconfirmed 明确说明不确定性 | 将推断或未来设想描述成当前事实 |
| 基础交互 | SVG 载入；点击节点打开详情；关闭、平移、缩放和 Fit 可用 | 面板无法关闭、缩放漂移明显 |
| 图内操作说明 | 固定图例清晰分为阅读说明、证据状态与操作；操作文案明示点击、`Tab`、`Enter`、`Esc`，并与实际行为一致且已本地化 | 组名与内容混淆、缺失操作提示、文案与行为不一致 |
| 可选可用性（仅在用户确认时） | `Tab` 可达节点，`Enter` / 空格打开，`Esc` 关闭详情；小视口下详情面板可用 | 键盘无法进入节点、按键无效、窄屏面板不可用 |
| 视觉层级 | 三种状态可区分；标题不遮挡节点；详情层级清晰 | 仅靠文字区分状态、子图标题盖住节点 |
| 隐私与输出边界 | HTML 中没有密钥、凭据、敏感路径或用户绝对路径；输出位置为相对路径 | .env、私钥、用户目录或内部绝对路径被写入产物 |
| 失败降级 | 网络或完整性校验失败时显示说明性失败页，不执行被篡改脚本 | 空白页、静默失败或加载篡改内容 |

验收人应记录：输入目录、问题、生成的相对 HTML 路径、浏览器版本、每项结论及必要的截图或复现步骤。
