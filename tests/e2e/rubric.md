# 交互式证据图谱端到端验收量表

本量表用于检查一次真实的（代码目录 + 业务问题）或（非代码业务流程描述）→ MapSpec → 单个 HTML 生成。它不比较字节级快照；每项必须有清晰的通过或失败结论。

| 维度 | 通过条件 | 失败示例 |
| --- | --- | --- |
| 图谱范围 | 节点、边和分组回答了输入问题，范围没有无依据地扩大 | 将未读取的模块写成已实现流程 |
| 证据可追溯 | 所有 verified 项都有存在的相对路径、真实行号和准确描述 | 行号越界、文件不存在、把推断标成 verified |
| 证据状态诚实 | inferred 与 unconfirmed 明确说明不确定性；每个节点左上角都有与图例一致的可见状态点 | 将推断或未来设想描述成当前事实，或只能打开详情后才能识别节点状态 |
| 基础交互（flowchart；sequence 见下行） | SVG 载入；点击节点打开详情；点击任意关系线钉住与悬停同款的高亮动画（同时仅一条，可取消且悬停不受影响）；关闭、平移、缩放和 Fit 可用 | 面板无法关闭、缩放漂移明显、点击关系线无反应或拖动画布误清钉住 |
| 时序图交互（`meta.diagramKind=sequence` 时） | 点击消息文本/线/序号或参与者打开对应证据详情并保持单选中高亮，关闭或 `Esc` 清除；autonumber 序号与声明消息一一对应；消息线计数与声明一致；全产物无 `foreignObject`；帧条件在窄帧换行下原文完整可见 | 点击消息无反应（panzoom 捕获重定向）、多选高亮并存、序号缺失、帧条件被实体残片拆坏或消息文本静默丢失 |
| 图内操作说明 | 固定图例清晰分为阅读说明、证据状态与操作，并与实际行为一致且已本地化。flowchart：操作文案明示点击卡片、点击关系线钉住、`Tab`、`Enter`、`Esc`；sequence：操作文案明示点击消息或参与者、单选中、`Tab`、`Enter`、`Esc`，不出现关系线钉住 | 组名与内容混淆、缺失操作提示、文案与行为不一致、时序图图例仍写节点与关系线钉住 |
| 可选可用性（仅在用户确认时） | flowchart：`Tab` 可达节点与关系线胶囊，`Enter` / 空格打开详情或钉住关系，`Esc` 关闭详情并清除钉住；sequence：`Tab` 可达消息文本/线/序号与参与者，`Enter` 打开详情，`Esc` 关闭；两者在小视口下详情面板可用 | 键盘无法进入节点或消息、按键无效、窄屏面板不可用 |
| 视觉层级 | 三种状态可区分；标题不遮挡节点；详情层级清晰 | 仅靠文字区分状态、子图标题盖住节点 |
| 隐私与输出边界 | HTML 中没有密钥、凭据、敏感路径或用户绝对路径；输出位置为相对路径 | .env、私钥、用户目录或内部绝对路径被写入产物 |
| 失败降级 | 网络或完整性校验失败时显示与 `uiLocale` 一致的说明性失败页，不执行被篡改脚本 | 空白页、静默失败、语言混杂或加载篡改内容 |

验收人应记录：证据根目录、问题、生成的相对 HTML 路径、浏览器版本、每项结论及必要的截图或复现步骤。
